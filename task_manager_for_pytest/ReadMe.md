Данный Менеджер задач создан для того чтобы изучить библиотеку Pytest и попрактиковаться с тестами, в качестве базы данных используется Python Dict().
Стек: Python, FastAPI, Pytest, TestClient

Тестировал получение, создание, обновление и удаление задач. Граничные случаи и если ID несуществует

Тесты запустить следующим образом pytest tests.py -v
